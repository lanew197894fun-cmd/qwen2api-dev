🔧 常見問題

Q: 注入後服務需要重啟嗎？
不需要，立即生效。下次請求就會使用新的 cookies/token。

Q: cookies 多久過期？
ssxmod_itna 每 15 分鐘重新整理，但系統內建 SSXMOD 管理器會自動處理。token 過期後需重新注入。

Q: 為什麼要注入 cookies？
新鮮的 acw_tc、ssxmod_itna 等 cookies 能幫助繞過 WAF 阻擋，提升請求成功率。

Q: 注入後還是 500 / 光說不做事？
不能只貼 cookies！Qwen access token 在瀏覽器 localStorage（鍵 token），請 F12 → Console 執行 localStorage.getItem('token') → 把輸出貼到 Token 欄。沒有 token，免額路徑必定全滅（refresh 端點 auth.qwen.ai 目前全方法 405）。

Q: API Key 是什麼？
本機開發預設 AUTH_DISABLED=true，不需要任何 API Key；若伺服器關閉了 AUTH_DISABLED，需輸入伺服器 .env 中的 ADMIN_KEY。
